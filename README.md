# Trivio v2 — редизайн главной trivio.ru

Awwwards-стиль лендинг по плану `plan-rabot.md`: full-width с паддингами 150px,
сквирклы (corner smoothing 0.6), GSAP-анимации, Lenis smooth scroll, фото-заглушки.
Весь контент — дословно с trivio.ru, эталон: `structure.md`.

## Запуск

Статика без сборки — открыть `index.html` в браузере (двойной клик) или поднять сервер:

```bash
npx serve .        # или python -m http.server
```

GSAP/Lenis/шрифты грузятся с CDN — нужен интернет. Без интернета страница
работает статично (весь контент виден, анимации выключаются сами).

## Решения и отклонения от плана (по итогам совета 2026-07-17)

- **Стек зафиксирован**: vanilla + классические скрипты с CDN, без сборки —
  проще интегрировать в Tilda/CMS. React-вариант из §7 плана не используется.
- **MorphSVG исключён**: морф «стрелка → галочка» в формах сделан простой заменой
  символа — визуальный эффект тот же, минус целый плагин.
- **Один пин вместо двух**: пин со scrub — только галерея кейсов (§3.7).
  Тёмная мозаика (§3.8) — drag-карусель с multi-speed параллаксом, без пина:
  два пина подряд — главный риск по 60fps.
- **Сквирклы**: clip-path заменяет рамки карточек на drop-shadow-контур
  (clip режет border по углам). Фолбэк без `clip-path: path()` — border-radius.
- **H1 ~104px максимум** (план допускал 110): проверено на реальных русских строках —
  «Удобные командировки» на 1440px ложится в две строки без переносов.

## Производительность и доступность

- Анимации — только `transform`/`opacity`; один общий тикер GSAP; `content-visibility: auto`
  на тёмной мозаике.
- `prefers-reduced-motion: reduce` — отключает Lenis, пины, параллаксы, marquee,
  SplitText и прелоадер; контент виден сразу.
- Без JS: прелоадер скрыт через `<noscript>`, весь контент доступен, карусели
  скроллятся нативно.
- Мобайл: пин кейсов заменяется на drag; паддинги 20px; hover-тексты ролей раскрыты.
